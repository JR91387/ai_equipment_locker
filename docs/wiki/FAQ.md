# FAQ

**Will it change my settings?** No. It only reads folder listings and writes its own catalogue file.

**Why is a tool missing?** It may keep its files somewhere the built-in list does not know. Pin the folder from
the page, and consider opening an issue so it can join the list.

**Why does a size say "≥"?** Very large folders are counted up to 10,000 files to keep the disk quiet.

**What does "third-party" mean on a card?** The file was found inside downloaded code such as `node_modules`.
It is shown separately so your own work stands out.

**Can I see what changed?** Each folder's detail panel lists its recent changes; notes keep every earlier version.

**How do I start over?** Stop the page and delete the catalogue file (see Getting started).
